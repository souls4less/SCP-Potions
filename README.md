# SCP Potions

A small Forge 1.20.1 mod that adds brewing recipes for some of ZCoper's SCP mods.

Supported SCP mods are optional. Recipes are available only for installed mods. Some ingredients can be collected by crouching and right-clicking the relevant SCP with a glass bottle.

## Installation

Install Minecraft 1.20.1 with Forge 47.x, then put the SCP Potions JAR in your `mods` folder alongside any supported SCP mods. JEI support is optional.

The source ZIP is not a playable mod.

## Build from source

On Windows, install a Java 17 JDK and run `BUILD_ON_WINDOWS.bat`. The script downloads the official Forge 1.20.1 MDK and builds the mod. The resulting JAR is placed in `dist/`.
